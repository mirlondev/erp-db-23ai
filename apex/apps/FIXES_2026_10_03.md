## ✅ Corrections appliquées

### Règle d'or appliquée
**JAMAIS de NULL dans une colonne monétaire affichée à un utilisateur.**
- `col` → `NVL(col, 0)`
- `col1 - col2` → `NVL(col1, 0) - NVL(col2, 0)`
- `col * col2` → `col * NVL(col2, 0)`

### Alerte automatique Z caisse

Quand écart > 100 XAF OU session non clôturée, la colonne `alerte` affiche :
- `⚠️ Session non clôturée` — session pas encore fermée
- `⚠️ ÉCART > 100 XAF` — différence supérieure à 100 XAF
- `OK` — tout est normal

### Détails des fix

#### p00010 (Sessions)
```sql
-- AVANT
s.opening_balance, s.closing_balance

-- APRÈS
NVL(s.opening_balance, 0) AS opening_balance,
NVL(s.closing_balance, 0) AS closing_balance,
+ CA session protégée par NVL
ROUND((NVL(s.closed_at, SYSDATE) - NVL(s.opened_at, SYSDATE)) * 24, 1) AS hours
```

#### p00012 (Historique tickets)
```sql
-- AVANT
t.total_ht, t.total_ttc, t.tax_amount_1 AS total_tva, t.status

-- APRÈS
NVL(t.total_ht,    0) AS total_ht,
NVL(t.total_ttc,   0) AS total_ttc,
NVL(t.tax_amount_1, 0) AS total_tva,
NVL(t.total_ttc, 0) - NVL(t.tax_amount_1, 0) AS net_ht_calc,  -- net HT calculé
CASE t.status
  WHEN 'V' THEN 'Validé'
  WHEN 'A' THEN 'Annulé'
  WHEN 'R' THEN 'Retour'
  ELSE 'Inconnu'
END AS status_label,
t.status
```

#### p00014 + p00015 (Z caisse)
```sql
-- AVANT
s.opening_balance, s.closing_balance, s.theoretical_balance,
(s.closing_balance - s.theoretical_balance) AS ecart,

-- APRÈS
NVL(s.opening_balance,    0) AS opening_balance,
NVL(s.closing_balance,    0) AS closing_balance,
NVL(s.theoretical_balance,0) AS theoretical_balance,
NVL(s.closing_balance, 0) - NVL(s.theoretical_balance, 0) AS ecart,
CASE
  WHEN s.closed_at IS NULL THEN '⚠️ Session non clôturée'
  WHEN ABS(NVL(s.closing_balance,0) - NVL(s.theoretical_balance,0)) > 100
    THEN '⚠️ ÉCART > 100 XAF'
  ELSE 'OK'
END AS alerte,
```

Pour multi-tenant et rôles REGAL (CAISSIER, MANAGER, etc.), il faudrait :
1. Authentification custom (PL/SQL Function Body)
2. Authorization schemes liés à `app_sys.sys_role`

3. **Calculs** : `col1 - col2` → `NVL(col1,0) - NVL(col2,0)`
